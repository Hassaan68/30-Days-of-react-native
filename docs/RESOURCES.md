## Essential Developer Tools

- **React Native Directory:** <https://reactnative.directory/> — Search and verify New Architecture and Expo Go compatibility before installing any third-party package.
- **Expo Snack:** <https://snack.expo.dev/> — Run and share quick React Native & Expo code experiments directly in your browser.
- **React Native DevTools:** Built into React Native 0.88 for inspecting component trees, console logs, network requests, and Hermes performance profiles.
- **Expo Orbit:** <https://expo.dev/orbit> — macOS/Windows menu bar app for launching simulators, emulators, and EAS builds with one click.
- **React Native Upgrade Helper:** <https://react-native-community.github.io/upgrade-helper/> — Compare native diffs when maintaining custom native projects.
