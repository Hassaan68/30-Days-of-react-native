## 2. Ask the Repository Community

- **GitHub Discussions:** Best place for learning questions, exercise hints, architecture feedback, and sharing your completed capstone projects.
- **GitHub Issues:** Use our issue forms if you found a bug in a code example, a broken link, a typo, or an outdated API. Please do **not** open bug reports for general troubleshooting questions before checking the Troubleshooting Guide and Discussions.

When asking a question, help others help you by including:
1. Which day or project you are working on (e.g., `days/day-11-api-integration`)
2. Your OS, Node version (`node -v`), and target runtime (Expo Go, iOS Simulator, Android Emulator, or Development Build)
3. The exact error message or stack trace
4. What you already tried
